# Phase 1 Plan 01: Walking skeleton, part 1 — the release-shaped reactor builds, locally and in CI

## Phase Goal

**As a** Java developer, **I want to** build a templated mail and send it through a Mailer account, **so that** the core contracts are proven before any real transport.

This plan is the first part of the Walking Skeleton (see `.planning/phases/01-library-core/SKELETON.md`): the Maven reactor, the wrapper, the `release` profile and CI, green before any Java source exists. Plan 01-03 adds the core contracts and plan 01-04 completes the thinnest send path; `SendThroughRecordingTest` and `RecordingTestJarSmokeTest` in plan 01-04 are the skeleton's end-to-end acceptance gate, and they pass before any expansion plan (01-05 templates, 01-06 failures) starts. Repository docs are plan 01-02.

## Acceptance Criteria

- [ ] `./mvnw -B -ntp verify`, `./mvnw -B -ntp -Prelease clean verify -Dgpg.skip -pl morimail -am` and `./mvnw -B -ntp -o verify` are green on the empty reactor.
- [ ] The CI workflow runs the same three commands on Java 17 with read-only permissions and SHA-pinned actions.
