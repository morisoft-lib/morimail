# Phase 1 Plan 05: Templated mail with attachments, and the full builder

## Phase Goal

**As a** Java developer, **I want to** build a templated mail and send it through a Mailer account, **so that** the core contracts are proven before any real transport.

This plan's slice: the developer fills a `MailTemplate` from a data map, attaches files, uses every address form of the builder, and gets one clear `InvalidMailException` for anything a transport could not send. It builds on the walking skeleton (plans 01-01, 01-03 and 01-04) and runs in parallel with plan 01-06, sharing no file.
