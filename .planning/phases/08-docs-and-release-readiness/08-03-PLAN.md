# Phase 8 Plan 03: stop step 5 deploys at a SNAPSHOT version (gap G-08-2)

## Phase Goal

A developer reading the README and docs can use inline images, and the build is ready for the owner to release 0.2.0.

This plan's slice is DOCS-06: the owner can release from docs/release.md. In UAT test 2 the owner reached a deploy while the POMs still read 0.2.0-SNAPSHOT. central-publishing-maven-plugin 0.12.0 sends a SNAPSHOT build to Central's snapshots repository, and it uploads unless `-DskipUpload` is set. The namespace has no snapshot publishing, so the result was HTTP 401 and nothing was stored. The doc had no guard, and its SNAPSHOT note described the plugin wrongly. The owner then finished step 4, ran the release and reported on 2026-11-23 "release worked now". The tag v0.2.0 is on 2c4ea80, and 8df5f6a bumped the POMs to 0.3.0-SNAPSHOT. This plan corrects step 5 of the doc for the next release and changes nothing else.
