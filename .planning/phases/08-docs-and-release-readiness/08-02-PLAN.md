# Phase 8 Plan 02: `docs/release.md` for both published jars, rehearsed, and the release gate

## Phase Goal

A developer reading the README and docs can use inline images, and the build is ready for the owner to release 0.2.0.

This plan covers the release half. The owner follows one version-neutral `docs/release.md` that builds the bundle for the parent POM, `morimail` and `morimail-html`. The bundle it describes was just produced and checked in a rehearsal that uploaded nothing. After the rehearsal's cleanup the two gate builds are green, so the owner can push, wait for Temurin 17 CI and release.
