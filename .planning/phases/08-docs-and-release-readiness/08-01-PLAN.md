# Phase 8 Plan 01: Inline images, `morimail-html` and the sample's `inline/` directory, documented

## Phase Goal

A developer reading the README and docs can use inline images, and the build is ready for the owner to release 0.2.0.

This plan covers the reading half. A library user finds a copyable inline-image example, a copyable `HtmlImages` example with the `morimail-html` coordinates, and a campaign author finds the `inline/` rules in the README and in the `send` usage text. The spec and the architecture page describe what the code does, including the property names Graph receives and the owner's live result. Plan 08-02 covers the release half.
