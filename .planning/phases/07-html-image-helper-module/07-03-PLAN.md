# Phase 7 Plan 03: The storable data: form and the phase gate

## Phase Goal

A template author can write ordinary image URLs in an HTML template, and one call to `HtmlImages` turns them into `cid:` references plus inline images that pass the Phase 5 checks.

This plan's slice: the storable form (HTML-07, spec section 10.4 "Storable form", owner request 2026-11-23). Task 1 (tracer) adds `toDataUris` and the `data:` decoding in `embed` with a work directory, proven by the D-24 round trip through `recording`. Task 2 pins the `data:` and `toDataUris` edges and runs the phase gate, including the final D-03 proof that `morimail` is unchanged.

## Acceptance Criteria

- [ ] `toDataUris` gives HTML whose images are `data:` URIs and that needs no image files; `embed` with a work directory turns it back into `cid:` references plus inline images with the original bytes, which pass `build()` for every record.
- [ ] Non-image, non-base64, malformed and oversized `data:` sources fail with `InvalidMailException` naming the source by position, never the payload.
- [ ] The three CI commands are green on JDK 21; the `morimail` jar equals the one built from f9b2f57; the final Temurin 17 run is an end-of-phase owner check.
