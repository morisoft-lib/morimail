# Phase 3 Plan 06: Graph text out of failure messages and a race-free log test (gaps G-03-2, G-03-4)

## Phase Goal

**As a** Java developer, **I want to** send mail through Microsoft Graph as an Entra app, **so that** each failure says whether to retry, drop the mail or fix the account.

This plan's slice: the owner's live test and the first Temurin 17 CI run found two gaps. A live 404 `ErrorInvalidUser` put the sender address into the exception message, because `GraphTransport.failure` appends Graph's free-text `error.message` (G-03-2). CI run 45016998414 failed twice in `./mvnw verify` because `EntraTokenErrorsTest.nothingSecretReachesALogOrAMessage` reads plain `ArrayList`s that other threads write through a root-logger handler (G-03-4), so the release build and the `unshare --net` step never ran.

## Acceptance Criteria

- [ ] A Graph failure message carries the HTTP status, the code and the request-id, and no Graph free text. A test with an address in Graph's text proves it in the library and through the sample's stop line and journal.
- [ ] docs/architecture.md, GRAPH-08 and Phase 3 success criterion 4 record the narrower message.
- [ ] The root-logger capture in EntraTokenErrorsTest is thread-safe, and its assertions are unchanged.
- [ ] The three CI commands pass on JDK 21. Three commits are made with the maintainer identity and none is pushed. The SUMMARY hands the Temurin 17 run to the owner.
