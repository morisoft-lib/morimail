# Phase 3 Plan 01: The send path, end to end, before anything else

## Phase Goal

**As a** Java developer, **I want to** send mail through Microsoft Graph as an Entra app, **so that** each failure says whether to retry, drop the mail or fix the account.

This plan's slice: the thinnest real path through every layer the phase touches. A secret-authenticated `EntraClientCredentials` gets a token from a WireMock token endpoint, a `graph` account built through the registry sends one text mail to a WireMock sendMail endpoint, and the 202 returns normally. Plans 03-02 (Entra) and 03-03 (Graph request and limits) then expand the two halves in parallel without touching the same file, plan 03-04 completes the Graph error mapping and the 401 retry, and plan 03-05 wires the sample and the live test.

## Acceptance Criteria

- [ ] A text mail sent through `Mailer` and a registry-built `graph` account reaches WireMock with the bearer token from the WireMock token endpoint, and the 202 returns normally.
- [ ] `graph` is a built-in provider, not a ServiceLoader entry, and cannot be overridden by an external jar.
- [ ] Timeouts and the no-redirect rule are set from the first line of HTTP code.
- [ ] The doclint release build and the import rules stay green.

## Flagged assumptions

- **Tracer gaps, each filled later without an architectural change.** No token cache yet (plan 03-02 adds it behind the same `accessToken`); no certificate flow yet (plan 03-02 adds two factories to the same class); `validate` checks nothing yet and the request carries only subject, one body and the to-recipients (plan 03-03 adds the full body, attachments, options and limits, and plan 03-04 the 401 retry and the full error mapping, inside the same two graph classes). A gap here is a missing branch, never a different shape.
- **Unclassified probe item ENTRA-01 (left unresolved).** Reviewed: the form is built from URL-encoded names and values in a fixed order, and the tracer test uses a secret with `+`, `&`, `=` and `%`. Open: how Entra itself treats unusual secrets beyond the documented "URL-encode it" is not probed.
- **Unclassified probe item ENTRA-04 (left unresolved).** Reviewed: `authority(URI)` accepts an absolute http or https URI with a host, strips one trailing slash and returns a new instance; plan 03-02 makes the assertion `aud` follow the overridden token URL. Open: a sovereign cloud also needs another Graph scope; that is a deferred idea in 03-CONTEXT.md.
- **No defaultFrom check in the transport.** `Mailer` applies the account's default sender before `validate` and `send` (Phase 1), so the transport always sees a from-address.
