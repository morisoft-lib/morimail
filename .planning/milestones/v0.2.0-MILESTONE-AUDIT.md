## Checker warnings, not counted as debt

- **Dry-run skips `mailer.validate`:** by design. A dry run builds no mailer (spec §8.3). `PreflightTest#dryRunReportsTheSameProblemsWithoutTheMailer` pins this.
- **The dry-run rewrite covers the whole HTML, not only `src`:** this matches the core's whole-body `cid:` scan (an accepted trade-off in `docs/architecture.md:40`) and touches the dry-run output only.
- **"Live test not executed":** wrong. The owner ran it on 2026-11-23 and it passed (`docs/architecture.md:40`). Claude does not run it.
- **"Send loop not traced":** closed. The loop at `SendCommand.java:346ff` sends `mails.get(i)` unchanged.
- **Work-directory lifetime:** documented (the caller owns the work directory, README:141).
- **Duplicate rule differs between helper and core (new, 271f262):** the helper folds case when it picks IDs (`HtmlImages.java:344`), but the core (`Mail.java:450,492`) and the sample pre-flight compare exactly. The helper is stricter, so it never emits IDs the core rejects. The core Javadoc (`Mail.java:341-343`) says ids that differ only in case count as distinct and advises against them. The only exposure: a caller adds `.inline(..., "Logo")` and then embeds `logo.png`, and the core accepts both. This is the documented limit (the helper does not see the caller's IDs). No test crosses helper and core on a case-variant pair. Owner's call whether to tighten the core; not counted as debt.
