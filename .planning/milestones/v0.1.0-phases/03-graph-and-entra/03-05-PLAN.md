# Phase 3 Plan 05: The sample sends for real (against WireMock), the owner's live test, and the record

## Phase Goal

**As a** Java developer, **I want to** send mail through Microsoft Graph as an Entra app, **so that** each failure says whether to retry, drop the mail or fix the account.

This plan's slice: the consumer. After it, `serial-mail send` builds a real Entra token provider and a registry-built graph account from account.properties and the environment, sends the example campaign end to end against WireMock for both endpoints, stops before sending when a credential is missing, and stops with exit 3 on a rejected mailbox. The owner gets a `live` test for the STOP report, CI proves the build needs no network, and docs/architecture.md records every deviation of the phase. It depends on plans 03-02 (certificate flow and cache), 03-03 (full Graph request and limits) and 03-04 (Graph error mapping and the 401 retry).

## Acceptance Criteria

- [ ] The example campaign goes out once through WireMock (one token request, five sendMail calls), and a rerun sends nothing.
- [ ] Missing or broken credentials stop the run in pre-flight (exit 2) naming keys only; a 403 stops it with exit 3.
- [ ] The live test is ready for the owner, excluded by default, and fails fast without its variables.
- [ ] CI has a network-free build step, and docs/architecture.md holds the phase's deviations and Microsoft-doc differences.

## Flagged assumptions

- **The network-free CI step cannot be rehearsed in this workspace.** The workspace container lacks the capability to create a network namespace (`unshare` fails even through sudo). The step runs on the GitHub runner, where sudo has it. Locally the executor runs the same Maven command without the namespace (`./mvnw -B -ntp -o verify`). The owner's next push proves the step; if the runner refuses it for an environment reason, the owner reports it with the STOP report and nothing is changed silently.
- **No defaultFrom on the sample account.** SendCommand sets `from` on every mail, so the account needs none, and leaving it out means no MailAccount message can echo a value from account.properties.
- **One WireMock server serves both endpoints.** The token path `/{tenant}/oauth2/v2.0/token` and the Graph path `/v1.0/users/...` cannot collide; D-13's "WireMock for both" is met by one in-process server.
- **realMailer stays covered without the real environment.** Two Phase 2 tests keep calling `SerialMail::realMailer`, with variable names no normal environment sets (`Sentinel-7f3a`, which contains a hyphen, and `MORIMAIL_TEST_UNSET_VARIABLE`). SendRunTest switches to `mailer(...)` with an empty environment, because its account names `MAIL_CLIENT_SECRET`, which an owner may really set during a live session.
- **Not a live run.** The `-Plive` check in Task 3 removes every MORIMAIL_LIVE_* variable first, so the class fails in @BeforeAll before any network call. Never run `-Plive` with those variables set; the owner runs the live test.
- **STOP after this plan.** It is the last plan of Phase 3. After verification and commit, report to the owner (ROADMAP Phase 3 STOP checkpoint list) and do not start Phase 4.
