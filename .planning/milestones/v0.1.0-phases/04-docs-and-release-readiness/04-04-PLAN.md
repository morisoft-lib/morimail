## Phase Goal

**As a** repository owner, **I want to** get the setup guide, final docs and a release rehearsal shaped by the live test, **so that** I can set up my tenant and publish 0.1.0.

This plan's slice: DOCS-04 and roadmap success criterion 5. The release profile is rehearsed end to end at the real version, with signing, bundling and inspection and with nothing sent.
