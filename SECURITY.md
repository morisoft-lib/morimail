# Security Policy

## Reporting a vulnerability

Please report a vulnerability privately through GitHub private vulnerability reporting: https://github.com/morisoft-lib/morimail/security/advisories/new (the "Report a vulnerability" button on the Security tab of the repository).

If that is not available, send an email to stephan@morisoft.de.

Please do not open a public issue for a vulnerability.

## Supported versions

morimail is pre-1.0. Fixes go into the latest release only.
